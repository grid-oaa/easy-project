# 虚拟机前置服务安装（Nacos + MySQL + Redis）

> 目标：在虚拟机 `192.168.200.128` 上使用 Docker Compose 启动必须的前置服务。  
> 说明：请根据你的虚拟机系统选择对应的安装步骤。

## 1. 安装 Docker（Ubuntu 22.04 示例）
```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg lsb-release

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

sudo systemctl enable docker
sudo systemctl start docker
```

## 2. 安装 Docker（CentOS 7/8 示例）
```bash
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
sudo yum install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

sudo systemctl enable docker
sudo systemctl start docker

// 更改镜像源
 vim /etc/docker/daemon.json
{
  "registry-mirrors": [
    "https://docker.1ms.run",
    "https://hub.rat.dev",
    "https://dockerproxy.net",
    "https://proxy.vvvv.ee"
  ]
}

```

## 3. 准备 docker-compose.yml
在虚拟机上创建目录并写入配置：
```bash
mkdir -p ~/easy-infra
cd ~/easy-infra
```

创建文件 `docker-compose.yml`：
```yaml
version: "3.8"

services:
  nacos:
    image: nacos/nacos-server:v2.3.0
    container_name: easy-nacos
    restart: unless-stopped
    environment:
      - MODE=standalone
    ports:
      - "8848:8848"
      - "9848:9848"
      - "9849:9849"
    healthcheck:
      test: ["CMD", "curl", "-f", "http://192.168.200.128:8848/nacos/"]
      interval: 10s
      timeout: 5s
      retries: 5

  mysql:
    image: mysql:8.0
    container_name: easy-mysql
    restart: unless-stopped
    environment:
      - MYSQL_ROOT_PASSWORD=root
      - MYSQL_DATABASE=easy_auth
    ports:
      - "3306:3306"
    command: ["--character-set-server=utf8mb4", "--collation-server=utf8mb4_unicode_ci"]

  redis:
    image: redis:7.2
    container_name: easy-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
```

## 4. 启动前置服务
```bash
cd ~/easy-infra
docker compose up -d
docker compose ps
```

## 4.1 虚拟机重启后自动启动容器
如果已按上面的 `restart: unless-stopped` 配置创建容器，Docker 服务启动后会自动拉起容器。

如需对已存在的容器补充重启策略，请执行：
```bash
docker update --restart unless-stopped easy-nacos easy-mysql easy-redis
```

## 5. 访问与端口
- Nacos: `http://192.168.200.128:8848/nacos`
- MySQL: `192.168.200.128:3306`
- Redis: `192.168.200.128:6379`

## 6. 防火墙与连通性检查
如果无法访问，请放通端口：
```bash
# Ubuntu (ufw)
sudo ufw allow 8848
sudo ufw allow 3306
sudo ufw allow 6379

# CentOS (firewalld)
sudo firewall-cmd --add-port=8848/tcp --permanent
sudo firewall-cmd --add-port=9848/tcp --permanent
sudo firewall-cmd --add-port=9849/tcp --permanent
sudo firewall-cmd --add-port=3306/tcp --permanent
sudo firewall-cmd --add-port=6379/tcp --permanent
sudo firewall-cmd --reload
```

## 7. 连接示例（本地开发机）
在本地项目的环境变量中配置：
```
NACOS_ADDR=192.168.200.128:8848
MYSQL_HOST=192.168.200.128
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=root
AUTH_MYSQL_DB=easy_auth
PERMISSION_MYSQL_DB=easy_permission
REDIS_HOST=192.168.200.128
REDIS_PORT=6379
```

## 8. 常见问题
- 若 Docker Compose 命令不可用，请确认安装了 `docker-compose-plugin`。
- 若 Nacos 无法访问，检查虚拟机网络模式与端口映射。
